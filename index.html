v1.2 CXI-1946
2026-07-10
Developer Designer Tester
Body Scale
Body/XXL hinzugefügt
Neue oberste Body-Stufe für große Leseformate (Magazine, Editorial-Bereiche). Body/XXL/Regular Body/XXL/Medium Body/XXL/Underline  ·  20px / lh 28px
Body/XL — Werte angepasst
Body/XL  20px / lh 28px → 18px / lh 24px  — bisherige XL-Werte werden jetzt von Body/XXL geführt.
Body/XS hinzugefügt
Kleinste Body-Stufe für Timestamps, Badges, Legal-Micro-Labels. Nur für nicht-essentielle Textelemente. Body/XS  ·  10px / lh 14px
Figma Variables
Typography Variable Collection eingeführt
Alle Text Styles sind mit Figma Variables verknüpft. Typography / Primitives und Typography / Semantic. Dev Mode liefert ab sofort Token-Namen statt rohe px-Werte.

Action required
  • Developer: Alle body-xl Implementierungen prüfen — Font Size ändert sich von 20px auf 18px.
  • Developer: Neue Token --body-xxl-size: 20px und --body-xs-size: 10px in globales Stylesheet aufnehmen.
  • Designer: Bestehende Body/XL-Verwendungen prüfen — ggf. auf Body/XXL umstellen wo 20px gewünscht war.
  • Tester: Regression-Test für alle Screens mit Body/XL — visuelle Größe reduziert sich leicht.
